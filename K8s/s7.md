These three concepts are commonly asked together, so remember their purpose:

| Feature                           | Purpose                                           | When It Runs                                    |
| --------------------------------- | ------------------------------------------------- | ----------------------------------------------- |
| **initialDelaySeconds**           | Delay the first probe after container startup     | Before the first health check                   |
| **preStop Hook**                  | Execute cleanup logic before the container exits  | Just before termination                         |
| **terminationGracePeriodSeconds** | Give the application time to shut down gracefully | After `SIGTERM` and before forceful termination |

This trio is a very common Kubernetes interview topic because it tests your understanding of **application startup, health monitoring, and graceful shutdown**.
