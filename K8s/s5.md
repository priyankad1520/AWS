### Correction 1 (Scaling StatefulSet)

You said:

> "Kubernetes creates db0, db3 and db4."

This is incorrect.

If replicas increase from **3 → 5**, Kubernetes **does not recreate db0, db1, or db2**.

It only creates:

```
db-3
db-4
```

The existing pods remain unchanged.

### Correction 2 (Rolling Update Order)

You said:

> "Kubernetes terminates db0, then db1, then db2."

For a StatefulSet, the default **RollingUpdate** updates **from the highest ordinal to the lowest**.

For example:

```
db-2
↓

db-1
↓

db-0
```

This preserves quorum for many distributed databases.
